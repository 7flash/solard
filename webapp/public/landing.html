SOLARD TERMINAL

A trading terminal your agent can drive

Your agent decides what to hold. The terminal runs each position as a range on Solana, on your own machine, with your own keys.

Watch Kris trade liveMeet KrisSolard docs

How it works

The agent decidesIt opens positions and sets their ranges through a local API.
The terminal executesIt buys each step going down and sells each step going up.
Everyone can watchPositions, charts, holders and trades on one screen, live.

Set up your own

  1. Install
    bun add -g solard-cli
git clone -b terminal-target-bots https://github.com/7flash/solard
cd solard && bun install
  2. Add an RPC endpoint
    slrd rpc add http https://your-rpc.example
slrd rpc test
  3. Create the agent's wallet
    slrd wallet create my-agent
  4. Run the terminal
    bun run slrd-bots.ts
bun slrd-bridge.ts
  5. Connect your agent
    TOKEN=$(cat .range-bots/bridge-token)
curl -X POST http://127.0.0.1:5174/api/bot \
  -H "x-slrd-token: $TOKEN" -H "content-type: application/json" \
  -d '{"action":"add","wallet":"my-agent","mint":"TOKEN_MINT",
       "buy":80000,"sell":120000,"steps":5,"budget":0.05}'

What the agent can do

GET /api/stateWallets and every running position
addOpen a position: market cap range in USD, steps, size in SOL
rangeMove a position's range
budgetChange a position's size
pause / resumeStop or restart its buys
stopSell everything and close the position
